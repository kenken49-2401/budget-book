# Budget Book

無料で使う個人用の家計簿。スマホとPCで同じデータを扱い、レシート画像も保存することを目標とします。

## 現在の段階

開発初期です。現時点では金額・日付の検証と月別集計の基礎のみ実装しています。画面、保存、同期、認証、写真、OCRは未実装です。実際の家計データを入力する用途にはまだ使えません。

## 方針

- GitHub Pagesで画面を配信し、個人の家計データや写真、秘密情報を公開リポジトリに含めない。
- 無料プランを前提にし、有料APIや自動課金を組み込まない。無料枠の制限やサービスの休止を想定する。
- 本人だけが使う。認証と保存先のアクセス制御を検証してから実データを扱う。
- 写真の文字認識結果は保存前に確認・修正できるようにする。無料で動作するOCRを検証する。
- データと写真のバックアップ・復元を用意する。ChatGPT連携は後回し。

## 保存先の候補

Supabase Freeは候補の一つ。公式の料金説明ではDB 500 MB/プロジェクト、Storage 1 GB（組織の使用量）を含む。容量・通信量の上限や低稼働時の休止に注意。枠は変わるため導入前に再確認する。アクセス制御、写真の容量、バックアップ、OCRの日本語精度を検証してから採用を決定する。GitHub Pages自体は書き込み先ではない。

## 開発順序

1. 金額・日付の検証と月次集計の基礎。
2. 手入力画面と一覧・編集・削除。
3. 本人認証と端末間の安全な保存・同期。
4. 写真の保存・表示とバックアップ・復元。
5. 無料OCRの精度・端末対応を検証し、確認画面に組み込む。
6. 必要に応じてChatGPT連携を検討。

## テスト

Node.js 18以上で `node --test tests/*.test.mjs` を実行します。依存パッケージはありません。
