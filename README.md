# Budget Book

無料で使う個人用家計簿の試作です。GitHub Pages向けの静的アプリとして作っています。

## 現在できること

- 支出・収入の追加、編集、削除、月別の収支とカテゴリー別集計
- レシート写真（JPEG・PNG・WebP、元ファイル20 MB以下）を自動縮小して保存し、無料OCRで合計と商品名、カテゴリーを推定
- 記録と写真を含むJSONバックアップの書き出し、復元

**現状はブラウザ内だけに保存します。端末間の自動同期・ログインは未実装です。** 保存領域の上限はブラウザごとに異なり、写真を複数登録すると上限に達することがあります。ブラウザのデータを消すと記録も消えます。定期的にバックアップしてください。JSONには記録と写真が暗号化されずに含まれるため、安全な場所に保管してください。復元するとそのブラウザの全記録が置き換わります。

## レシート読み取り

「記録する」からレシート写真を撮影または選択すると、ブラウザ内でOCRを実行し、合計・商品名・カテゴリーの候補を表示します。読み間違いや複数ジャンルを含む場合があるので、保存前に確認・修正してください。合計が特定できない場合は手入力します。1枚のレシートを1件の支出として保存し、商品名はメモの候補になります。写真を保管する際は縮小した画像を保存します。

無料のTesseract.jsと日本語・英語の言語データを使用します。初回はインターネット接続が必要で、外部配信元からプログラム・モデルをダウンロードします。写真の認識処理はブラウザ内で行います。端末や通信環境、写真によって処理時間や精度が変わります。失敗した場合は手入力できます。

## 試し方

リポジトリのフォルダで `python3 -m http.server 8000` を実行し、ブラウザで `http://localhost:8000/` を開きます。モジュールを使うため、HTMLファイルを直接開かずHTTPサーバーから使ってください。

GitHub Pagesへの公開にはリポジトリの Settings → Pages → Build and deployment の Source を **GitHub Actions** に設定してください。`.github/workflows/pages.yml` でmainブランチの内容を配信します。設定と公開状態の確認は別途必要です。公開されるのはアプリのソースだけで、ブラウザに保存したデータは公開されません。
